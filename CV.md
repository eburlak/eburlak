## Open source

Публикую переиспользуемые библиотеки на TypeScript без внешних зависимостей, лицензия MIT.

**[Библиотека графиков](https://www.npmjs.com/package/burlak)** - основной личный проект,
развиваю с 2018 года. Написана с нуля, без графических библиотек в зависимостях.

- Типы графиков: комбинированный, радарный, воронка, круговой, кольцевой
- Общее ядро отрисовки и единая система настроек для всех типов графиков
- Дополнительно в пакете набор утилит: HTTP-запросы, работа с датами, cookie,
  event emitter, работа с DOM и URL

**[maskit](https://www.npmjs.com/package/maskit)** - маски ввода: декларативный синтаксис
масок, подключение через data-атрибуты, колбэки жизненного цикла, поддержка кириллицы

**[notificit](https://www.npmjs.com/package/notificit)** - тост-уведомления: настраиваемые
анимации, режимы закрытия, кастомизация классов

На [GitHub](https://github.com/eburlak) - 30 собственных репозиториев, преимущественно
небольшие переиспользуемые библиотеки и утилиты.
